## umask 
- can be changed temporarily & permanently 
    - not recommended to be changed permanently 
    - to change permanently: edit in __bashrc__ file 
- default __umask__ 
    - 0022
- max permissions for file: 
    - 666 
- default permissions for file: 
    - 666 - umask 

- max permissions for dir: 
    - 777
- default permissions for dir: 
    - 777 - umask
