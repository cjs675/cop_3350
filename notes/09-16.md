## class notes (lecture 08) Vim & Practical Text Processing 


- vim begins in __command mode__ from default 

- commands: 

```
:x - save if needed & quit  (command mode)  
:X - delete char before cursor (insert mode) 
:q! - quit & discard changes 
:D - delete from cursor position to EOL  
gg - go to beginning of file 
G - go to end of file 
```


```
- copy, paste, redo, undo

yy - copy current line 
3yy - copy 3 lines 
p - paste copied text 
3p - paste copied line 3 times
u - undo last change  
ctrl+r - redo last change 
:r file - append a file with contents of another 

``` 
- to search a string: /string 
- to replace a string with another: 
```
:%s/string_to_replace/string/g
```
