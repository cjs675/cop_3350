- Cron/Crontab
    - useful for scheduling tasks to run programatically 

- __cron:__ general recurring scheduling facility
- __crond:__ background service that executes scheduled cron jobs 
- __crontab:__ user's table of scheduled commands 
    - command used most often
- to check if service is active: 
    
    ```systemctl is-active service_name
    ```
- to check if a service is currently scheduled: 
    
    ```
    crontab -l
    ```
- creating a cronjob (using crontab) 

    ```
    crontab -e (to open a new cronjob file) 
    
    schedule + command to run 

    ***** command 
    |||||_day of wk (0-6) 
    ||||_month (1-12) 
    |||_day of month (0-31)
    ||_hours (0-23)
    |__ minute (0-59)
    ``` 
- (ex.) 
    
    ```
    30 14 * * * 

    run every day at 2:30PM  

    0 0 * * * 

    run every day at midnight 
    ``` 

- (ex.) 
    
    ```
    0 * * * *  cp /abc /def

    copy contents of /abc into /def every hour 

    ```
- (ex.) 
    
    ```
    * * * * * command 

    command will run every minute
    ```
- (ex.) 

    - take backups Oct. 2nd at 11:59PM 

    ```
    59  23  2   *   * cp /etc/group /etc/group-backup
    ```


- (ex.) 
    - specify days of wk for given command to run 
    - every wkday at 6PM 

    ```
    0   18  *   *   1-5 command 
    ```
    - every monday at 8AM 

    ```
    0   0   8   *   1   command 
    ```

- cron expressions can be more flexible: 
    - range: 1-5 (values 1 through 5) 
    - list: 1,3,5 (values 1, 3, 5) 
    - step: */10 (every 10 values) 



- useful commands: 
    - crontab -l: list cureent crontab 
    - crontab -e: edit current crontab
    - crontab -r: remove current crontab
