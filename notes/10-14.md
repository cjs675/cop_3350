## ssh & sftp  

- verify ssh-server & ssh-clients are installed: 
    
    ```
    rpm -q openssh-server
    rpm -q openssh-clients
    ```

- both normally use TCP __port 22__ 
- ssh:  
    - secure shell 
    - encrypts communication between client & server
    - secure remote login & command execution

    - allowing SSH through __firewall__ 
    
    ```
    sudo firewall-cmd --state
    sudo firewall-cmd --get-active-zones

    sudo firewall-cmd --permanent --add-service=ssh
    sudo firewall-cmd --reload
    sudo firewall-cmd --list-services
    ```

- sftp:
    - secure file transfer through SSH  
    - upload files from client to server 
    - download files from server to client 
    - browser remote dirs
    - create & manage remote dirs 
    - supports secure file transfer, download & remote file management  
    - is __NOT__ equal to traditional FTP 
    - uses SSH auth & encryption
        - no separate FTP server needed 
    

------------------------------------------ 
   TASK                     Command
------------------------------------------  
 Start SSH Service         systemctl enable -now sshd 
 Connect Remotely          ssh USER@SERVER
 Run remote command        ssh USER@SERVER CMD 
 Start File Transfer       sftp USER@SERVER
 Upload File               put FILE
 Download File             get FILE
