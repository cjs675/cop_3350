## Lecture 14: Linux Networking Fundamentals 


- __ipv4__: 32 bits 
    - 4 segments
        - each 8 bits
        - 2^8
            - (0-255) 


- 24 bits for __network__ 
- 8 bits for __host__  


- typical NAT IPv4 address: 
    ```
    10.0.2.15/24
    ``` 

- each VM has two virtual network adapters: 
    - interface:   Network     Purpose 
        - enp0s3   NAT       
    - Network: 
    - Purpose:
