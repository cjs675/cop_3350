## class notes 

- package management & SW admin

- administrative habit --> don't install SW first & investigate later 
    - search
    - inspect
    - install
    - verify 


- package: 
    - structured unit used to distribute SW 
    - may contain: 
        - exe programs
        - libs
        - config files
        - docs
        - metadata bout the SW

- packge managers (specific to RHEL) 
    - rpm
    - dnf 

- why use DNF? 
    - works with repos & handles deps for us 
    - rpm works directly with RPM packages 

- when installing a package, can append with __-y__ 
    - to install with no further confirmations  

- to remove packages: 
    ```
    sudo dnf remove package_name -y
    ```
