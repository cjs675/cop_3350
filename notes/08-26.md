## managing user accounts and groups in linux

- good practice: make all commands/vars lowercase 

- creating user accounts:  
- need to set password as well

```bash
adduser name 
passwd password_here

useradd name
passwd password_here

```  

- to disable a password for a password:

```bash 
passwd -d chris 
```
- use _rarely_ / if ever, since will be able to login with just username  


- when we add a new user, we update 3 files under ```/etc```: 
    - passwd
    - shadow
    - groups


## to gain info on logged users 

```bash

w // details about logged usrs 
who // summary 
whoami // name of logged user
who am i // details about console 
tty // " " " 
```

- user info follows pattern of: 

```
username - encrypted password - user id - group id - comments - home dir - shell 
chris : x : 1005 : 1006 : Software Developer : home : sh 
``` 

```bash 
$x!   --> password given for user 
!!    --> no password given for user 
empty --> password disabled (very risky)
```


## viewing info of /etc 

```bash
cat /etc/passwd
cat /etc/group
cat /etc/shadow 
``` 


## modifying user accounts 

- can lock accounts via:  

```bash 

paswd -l user/group
``` 

- delete a user 

```bash 

userdel username (deletes w/o deleting homedir) 
userdel -r username (deletes recursively from whole system) 

``` 

## groups 

- create a group & add a new user to group: 

```bash
groupadd groupname

adduser username
passwd username 
usermod -aG groupname username  
```
