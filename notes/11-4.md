## Lecture 20: Shell Programming Fundamentals

- __Shell Script__ 
    - saves commands in a text file so the shell can execute them in sequence 


- Terminal
    - window in which you type commands and see output 
- Shell 
    - program that reads and interprets commands 
- Bash
    - common linux shell & scripting language 
- Shell Script
    - text file containing commands for a shell to execute 


- to ID your current shell: 

```
echo "$SHELL"
ps -p $$ -o comm=
command -v bash
bash --version
``` 


- __Key Idea:__ 
    - a bash script is plain text, not a compiled program 
    - #!
        - shebang marker at the beginning of a script 
    - /bin/bash
        - interpreter requested by the shebang 
    - # 
        - starts a comment (except in the shebang) 
    - "..."
        - double quotes keep spaces together and allow variable expansion
    - .sh
        - helpful filename convention, not required by bash 

- 3 ways to run a script: 

```
( method 1 ) 
bash hello.sh -- bash reads file, execute permission not needed 

( method 2 ) 
chmod +x hello.sh 
./hello.sh -- execute the file from this dir, needs execute permissions 

( method 3 ) 
source hello.sh -- run commands in current shell session   


Note: ./ refers to "the current directory"
```



### What is a variable? 

__Variable__ 
    - gives a name to a value that a script can resuse 
    - names may contain letters, digits, underscores
    - names must not begin with a digit 
    - bash variables are case-sensitive
    - use meaningful names such as course, student, or backup_dir
    - bash assignment syntax is strict about spaces 
    - space around causes errors 

```
Correct Variable Assignment: 

name="Alice" 

Incorrect variable assignment: 

name = "Alice" 
```


### Single quotes versus double quotes 


```
name="Alice" 
echo "Hello, $name"
echo 'Hello, $name'
echo "Your home is $HOME" 
```

- __Double Quotes:__ 
    - "..." allow variable expansion 
- __Single Quotes:__ 
    - '...' preseve chars literally  
- for most variable expansions, prefer __"$variable"__ 

   

### Braces clarify variable names 

```
file="report"
echo "$file.txt"
echo "${file}.txt" 
```

- braces become essential when letters follow the variable name





### Built-in Environment variables 

- USER 
    - current account name 

- HOME 
    - home dir 
- PWD
    - current working dir 
- SHELL 
    - login shell path 



### interactive input: the read command 

- a script can ask the person running it to enter info: 
    - read: 
        - read one line of input 
    - -r: 
        - do not treat backslashes as escape chars 
    - -p: 
        - show a prompt before reading 
    - name: 
        - variable that receives the entered text 


### command substitution

- useful when scripts need to store the output of a command rather than printing it immediately 

```
Syntax: 
    variable=$(command) 
```
