## useful commands  (quiz 1 review) 

- to modify a comment for a user:  

```bash
usermod -c "Comment" username 
```


- to lock a user's password: 

```bash
passwd -l username 
```

- to view all users logged in: 

```bash
who 

w 

whoami
```

- /passwd vs /shadow
    - /passwd visible by all users 
        - tracks basic id (UID, home dir, shell) 
    - /shadow only visible by root 
        - contains actual, salted user passwords 
        - password aging, expiration 


- to disable a password for a password:

```bash 
passwd -d chris 
```  

- is this command scrollable? 

```bash 
ls -la | more  

Answer: NO
```





## class notes 

### files, directories & filesystem nav in linux  

```bash 
/  --> root directory (top-level)  
 | 
 - /home (home dir of regular users) 
 - /etc (config files) 
 - /var (logs & other system data) 
 - /usr (programs, libs & shared resources) 
 - /temp (temporary files)  
 - /dev (device entities) 
 - /proc (process & kernel info) 
 - /root (home dir of root user)
```
- everything else appears somewhere below / 


- home dir: 

```bash
~ (tilde) 
```
- using it with a dir will take you to that dir itself 

```bash 
cd ~ (takes you back to home dir) 
cd /etc (takes you to etc) (absolute path -- begins with root/home dir)  
cd .. (takes you back to parent dir) 
cd - (takes you to previus working dir) 
cd . (present working dir) 
```

```bash
mkdir /sysAdmin (makes dir under root) 
mkdir sysAdmin  (makes dir under current working dir) 
```

- create nested dirs recursively 

```bash 
mkdir -p /dir1/dir2/dir3/dir4
```

- copying, moving, removing 

```bash 
cp source destination 
mv source destination 
rm file 
rm *a (removes every file beginning with given char via pattern matching) 
rm -rf (forcibly remove file recursively) 
rm -f *a (forcibly removes every file with a given char via pattern matching)
    - system won't ask to double check 
rm -rf *a (recursively remove all files in all dir beginning with given char) 


```
