# logs, monitoring, storage & system health 


- __collect evidence first__ 

- what is a system log? 
    - helps us answer: 
        - __what happened? when? what reported it?__ 
    - log records info about events occurong on the system 
    - may contains: 
        - service startup & shutdown
        - auth events 
        - errors & warnings 
        - hardware/kernel messages 
        - scheduled task activity 
        - application messages  
    - on RHEL
        - __systemd-journald__ collects system messages 
        - main inspection command: 
            - __journalctl__ 
            - tends to spit out lots of info 
                - best to narrow logs down to specifics 
        - useful first check:  

            ``` 
            journalctl -n 20
            // shows most recent 20 journal entries 
            ```
        - to follow new messages as they appear (live logs): 
            
            ```
            journalctl -f 
            ```
    - can inspect logs for __one service:__ 
        
        ```
        journalctl -u crond

        journalctl -u sshd
        ``` 
    - __activity:__ Inspect a Service log: 
        - choose service available 
            ```
            sshd
        - check its current status 
            ``` 
             systemctl status sshd
            ```
        - identify one timestamp 
        - identify one message associated w/ service
 
    - view logs for a particular service: 
        
        ```
        journalctl -u sshd -n 10
        
        // view 10 lines of sshd service logs 
        ```
    - to view events since __last boot:__ 
        
        ```
        journalctl -b 
        ```
    - view most recent (20) entries from current boot: 
        
        ``` 
        journalctl -b -n 20
        ``` 
    - RHEL stores useful logs under: 
        ```
        /var/log
        ```
    - to view RHEL logs: 
        ```
        ls -lh /var/log
        ```
    - inspecting log w/o opening everything

        ```
        sudo tail /var/log/messages

        sudo tail -n 20 /var/log/secure
        ``` 
        - to search for something specific: 
            ```
            sudo grep sshd /var/log/secure 
            ```

    - __uptime__ 
        - used to view current time system has been running for 
        - number of logged in users
        - __load averages__ 
        - may appear as 3 numbers  
            - value 1: 1 min. 
            - value 2: 5 min.
            - value 3: 15 min. 
        - load # __does not__ tell whole story 
            - interpret it together with: 
                - CPU count
                - process activity
                - workload 
                - trends over time 

    - check memory with __free:__ 
        
            ```
            free -h
            ``` 
        - total: installed memory
        - used: memory currently used
        - free: completely unused memory 
        - available: approx. memory available for work 
            - available memory best to take into consideration  

    - check filesystem space with __df__  
        ```
        df -h 
        ```
        - important columns include: 
            - filesystem: filesystem/device
            - size: total capacity
            - used: space used
            - avail: space available 
            - use %: percentage used 
            - mounted on: mount point 

    - df vs du
        - __df:__ how full is the filesystem?  
            - IDs filesystem pressure
        - __du:__ how much space is a dir/file using  
            - helps locate where space is being consumed 
        
    - to sort the output: 
        
        ```
        du -sh $HOME/* | sort -h  
        // ID which dirs are consuming most space 
        ```

    - inspect disks & block devices with __lsblk__ 
        - view attached external/storage devices 
        - typical info: 
            - disk names 
            - partitions
            - logical volumes 
            - sizes
            - mount points 
        - more informative view: 
            ```
            lsblk -f 
            ```
