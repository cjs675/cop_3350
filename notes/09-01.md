- __9 total permission chars__ 

- to change permissions (symbolic): 

```bash
chmod 
```

- to change ownership: 
 
```bash 
chown 
```

- file permission contents: 

```bash 
ls -l --> read permissions 

drwxrr-xr-x
||||  |   |
||||  |   
||||  -- group permissions 
| - read & write & execute 
- filetype

``` 

- (ex.) 

```bash 
ls -l 
-rw-r-r-. 1 student student 428 Aug 24 09:18 roster 
```
- student = owner
- student = group 
- 428 = size in bytes  


```bash 
9 permission chars (can be a mix of r/w/x) 

rwx    r-x     r-x
 |      |       | 
user  group    other
```

- a dash means the persmission is absent 
```bash 
r- 

```
    - can read but not execute or write 

- modifying permissions: 

```bash 

user = u
group = g 
other = o 
```

- format of mod'ing permissions: 

```bash 
symbol who  symbol  action 

u      user   +       add 

g      group  -       remove

o      other  =       set exactly 

a      all 


``` 

- (ex)
    - give user permission to execute file "roster" 

```bash  

# chmod u+x roster 
```

- (ex) 
    - remove 'other's' permission to read file 'roster'
```bash 
# chmod o-r roster 
```

- (ex) 
    - give all permission to execute file 'roster' 

```bash 
# chmod a+x roster
``` 


- (ex) 
    - give all ONLY read & write permissions   

```bash
# chmod a=rw roster 
```

- (ex) 
    - remove all permissions for __everyone__  
    - permissions left blank 

```bash 
# chmod a =  roster 
```
